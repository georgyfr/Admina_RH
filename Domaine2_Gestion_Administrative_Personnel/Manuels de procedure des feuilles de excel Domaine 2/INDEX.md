## Contenu type de chaque dossier

Chaque dossier de feuille contient :
1. **Manuel de procedure** (PDF) - Document complet avec chapitres, processus, conformite ISO
2. **Flowchart** (PNG) - Diagramme de la procedure CRUD
3. **Matrice d'acces** (PNG) - 6 profils x actions selon mode (Lecture / Lecture-Ecriture / Ecriture)
4. **Interface dynamique** (HTML) - Prototype interactif avec popups par mode d'acces
5. **Charts complementaires** (PNG) - KPIs, architecture, analyses selon la feuille
